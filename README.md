# WorkSmart Employee Productivity & Laziness Index Analysis

## Project Overview

This project analyzes employee productivity and work patterns at WorkSmart Pvt Ltd using Power BI. The analysis is based on 200 employee records and focuses on understanding employee activity, task completion, idle time, and the Laziness Index.

The main goal is to identify productivity patterns across departments and work modes and provide useful insights for HR decision-making.

## Problem Statement

WorkSmart Pvt Ltd wants to understand differences in employee productivity and identify departments that may need improvement. This project uses employee activity data to analyze productivity, task completion, missed deadlines, and work patterns.

## Project Objectives

- Analyze employee productivity across departments.
- Compare Work From Home and Office work modes.
- Understand employee task completion performance.
- Identify employees with a high Laziness Index.
- Study the relationship between social media usage and missed deadlines.
- Provide insights to support HR decisions.

- DAX calculated columns and measures

- Decomposition Tree
- What-If Parameter for break time reduction

## Key Findings

- Sales has the highest average Laziness Index among departments.
- Office and WFH employees show very similar average Laziness Index values.
- Employees who missed deadlines did not show higher average social media usage in this dataset.
- The relationship between meetings attended and task completion is very weak.
- The analysis highlights departments and employee groups that may need further investigation.
