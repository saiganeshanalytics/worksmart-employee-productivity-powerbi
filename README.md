# WorkSmart Employee Productivity & Laziness Index Analysis

## Project Overview

This project was created as a Power BI assessment for WorkSmart Pvt Ltd.

The main purpose of the project is to analyze employee productivity and identify patterns using the Laziness Index.

The dataset contains 200 employee activity records.

## Problem Statement

The HR department wants to understand employee productivity and identify departments or employee groups that may need further attention.

## Objective

The objective of this project is to analyze employee productivity using:

- Laziness Index
- Task Completion
- Department
- Work Mode
- Salary Level
- Social Media Usage
- Missed Deadlines
- Meeting Attendance

## Power BI Dashboard

The dashboard contains:

- Total Employees
- Average Laziness Index
- Average Completion %
- High Laziness Employees
- Adjusted Break Time
- Average Laziness by Department
- Login Hours vs Tasks Completed
- Work Mode vs Productivity Category
- Productivity Category Distribution
- Top 10 High-Laziness Employees

## Slicers

- Department
- Work Mode
- Salary Level

## Advanced Features

- Dynamic Title
- Conditional Formatting
- Employee Details Drillthrough
- Decomposition Tree
- Break Time Reduction What-If Parameter

## Key Findings

- Sales has the highest average Laziness Index.
- WFH does not show higher average laziness than Office work in this dataset.
- Salary levels show different productivity patterns.
- Social media usage has a very weak relationship with missed deadlines.
- Meeting attendance has a very weak relationship with task completion.
- IT needs further investigation when laziness and task completion are considered together.
